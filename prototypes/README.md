# 試作ラボ

AIと公式の公開データを使って作った、暮らしの試作・実験アプリを置くカテゴリです。

| フォルダー | 内容 |
| --- | --- |
| `wakekata/` | 8市のごみ分別案内「わけかた」 |
| `kosodate-compass/` | おでかけ・まちの比較ノート・家族の備え「こそだてコンパス」 |

カテゴリ入口は `index.html`。新しい試作は、このフォルダーの下にアプリごとのフォルダーを追加し、入口ページへ掲載します。

藤森式のキッズ向け教材・アプリは別のリポジトリで管理する方針です。このカテゴリは藤森式の公式製品やキッズ教材として扱いません。

各アプリはHTML・CSS・JavaScriptと公開データで動きます。APIキーは不要です。利用者の保存メモはブラウザーのlocalStorageに保存され、GitHubには送られません。保存先はURLのオリジンごとに異なるため、元のChatGPT Sitesで保存したメモは自動移行されません。

出典、データ時点、収録範囲は各アプリ内に掲載しています。自動更新はしません。公式機関の公式アプリではありません。
