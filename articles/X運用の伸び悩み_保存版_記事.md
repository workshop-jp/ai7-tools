## 5つの荷物と、心理学の研究

### 荷物① 「もしもの心配」

> リュックの底で、一度も開かれなかった雨具。

もしも炎上したら。もしも笑われたら。もしも失敗したら。
まだ起きていない雨のための荷物です。

アメリカの研究（2020年）に、こんなものがあります。
全般性不安症の人29人に、10日間、心配ごとを記録してもらい、30日間追跡しました。
その結果、**心配ごとの91.4%は、現実になりませんでした。**
（小さな調査です。詳しい但し書きは巻末に書きました）

私の解釈ですが、**「もしも」の荷物の多くは、実際には使われません。**
ただし、1割ほどは、本当に起きます。だから「全部捨てる」のではなく、**「最低限だけ持つ」**。その方法は、あとで書きます。

### 荷物② 「それっぽい作業」

> 登山口で、ルート比較表を作り込む人。表は完璧。そして、日が暮れる。

分析、研究、保存、整理、ツール選び。
忙しいし、進んでいる気がする。でも、投稿は出ていない。

アメリカの大学生1,106人の調査（2016年）では、
勉強を先延ばしするとき、「別の勉強」をしていた学生は、先延ばししない学生と、成績があまり変わりませんでした。
一方、**勉強と関係のない「それっぽい作業」に逃げていた学生は、結果が悪い**傾向がありました。
（相関の調査で、原因とは言えません）

「ノウハウ集め」が、この「それっぽい作業」にあたるのか。それを直接調べた研究は、見つけられませんでした。
でも、**「やっている感」と「進んでいること」は、別**です。

### 荷物③ 「他人の山頂」

> 頂上の写真は流れてくる。引き返した人の写真は、流れてこない。

タイムラインを見ると、「達成しました！」ばかり。
同じ時期に始めた人が、次々と成果を出している。

ここには、脳のクセが、3つ重なっています。

**クセ① 人は、周りと比べて、自分を測ってしまう（社会的比較）**
Facebookをよく使う人ほど自尊心が低く、その関係を「自分より上の人との比較の多さ」が説明した、という研究があります。

**クセ② 他人のつらさは、見えにくい**
人は、他人のネガティブな感情を、実際より少なく見積もる、という研究があります。
私の推測ですが、「達成しました」は投稿されやすく、「まだゼロです」「やめました」は投稿されにくい。

**クセ③ 見えているのは、「生き残った人」だけ（生存者バイアス）**
第二次世界大戦中の、有名な話です。
帰ってきた爆撃機の「穴の位置」を調べて、穴の多い場所に装甲を足そうとした。
そこで、数学者のウォルドは言いました。
**「穴のない場所こそ、危ない。撃たれて帰ってこなかった機体は、データにいないのだから」**

タイムラインも、同じ見方ができます。
流れてくるのは、**成果が出た人、続けた人**。やめた人、結果がゼロの人は、そもそも画面に出てきません。

つまり、**他人の山頂は、全員の山頂ではありません。**
比べる相手は、**先月の自分**にしましょう。

### 荷物④ 「毎日がんばる、という重さ」

> 山は、毎日登らなくていい。

毎日投稿しなきゃ。1日サボったら終わり。
その気持ちが、リュックをさらに重くします。

ロンドン大学（UCL）の研究では、新しい習慣が自動的にできるようになるまで、**平均66日**かかり、個人差が大きいと報告されました。
そして、**1日抜けても、影響は小さかった**。

完璧な毎日より、**「また戻れる」**ことの方が、ずっと大事です。

### 荷物⑤ 「宣言して、満足してしまう癖」

> 登山口で「頂上に行きます！」と宣言し、拍手をもらって、満足して帰宅。

「発信で稼げる人になります！」
そう宣言して、拍手をもらって、満足してしまう。

2009年の研究では、**「なりたい姿」を他人に認められると、努力が減りやすい**ことが示されました。人に認められることで、「もう半分なれた」ような気分になるから、と説明されています。
（1つの研究で、後の研究では逆の報告もあります。「宣言は必ず逆効果」ではありません）

私の工夫ですが、宣言するなら**「なりたい姿」ではなく「やる行動」**にします。
✕「稼げる人になります」 ○「月・水・金に1本書きます」

## 「最低限の装備」は、ちゃんと決まっている

ここで、大事なことを書きます。

**「最低限で歩き出せ」は、「何も持つな」という意味ではありません。**

登山には、**「必携品（テン・エッセンシャルズ）」**という決まりがあります。
アメリカの登山団体「The Mountaineers」が広めた考え方で、地図、ヘッドランプ、救急セット、予備の水、非常用の衣類などが含まれます。「出かける前に頭の中で確認するチェックリスト」として作られています。

大事なのは、ここです。
**最低限は、「ちゃんと決められている」。そして、決まっているからこそ、それ以外の「もしかしたら」を、手放せる。**

登山でも、発信でも同じです。
**「命綱（必携品）」は持つ。「もしかしたら」の荷物は、下ろす。**

## X運用の「必携品5つ」チェックリスト【保存用】

※ 登山の公式の必携品とは別物です。私が考えた「型」です。

- [ ] **① 地図（目的）**：誰の、どんな悩みに答える発信か。1行で言える
- [ ] **② コンパス（1つの窓口）**：今、力を入れる窓口は1つだけ（投稿の軸も1つ）
- [ ] **③ 水（続けられるペース）**：週何回なら、無理なく続けられるか。決めてある
- [ ] **④ 救急セット（炎上・変な人への備え）**：「知らない人が読んでも大丈夫？」と確認する。ミュート（気づかれない）・ブロック（気づかれる）を知っている
- [ ] **⑤ ヘッドランプ（振り返りの1行）**：週1回、「出した数」と「1つ気づいたこと」をメモする

この5つが、そろっていれば、**あとの荷物は、なくても歩き出せます。**

## リュックを軽くして歩き出す4つの方法

### ① 「もしも」を、紙に書き出して、仕分ける
感情を言葉にすると、不安に関わる脳の反応が小さくなる、という研究があります（画像を見たときの感情の実験で、書き出しはその応用です）。

「もしも」を、3つに分けます。
- 起きたら**命に関わる**（＝必携品で備える）
- 起きたら**困るが、後で直せる**（＝起きてから対処）
- 起きそうもないが**不安なだけ**（＝下ろす）

### ② 「もし〇〇したら、△△」で、歩き出す条件を決める
「そのうち投稿する」では、足は動きません。

> **「もし朝のコーヒーを入れたら、1行だけ書く」**

こういう「if-thenプラン」は、94のテストをまとめた研究で、効果量 d=0.65（中〜大）でした。
※ d=0.65は「成功率が65%上がる」という意味ではありません。

### ③ 天気は、歩きながら見る
登山口で空を見上げ続けても、天気は変わりません。
**歩き出して、はじめて分かること**が、あります。
そして、天気が変わったら、**引き返す**こともできます。引き返すのは、失敗ではなく、登山の基本的な判断です。

投稿も同じで、出してみて、反応が悪ければ、直せばいい。

### ④ 比べる相手は、「先月の自分」
他人の山頂ではなく、**先月の自分の標高**と比べます。
先月より、1つ多く出せた。1つ、反応があった。それが、登った分です。

## 14日間の「軽いリュック」プラン【保存用】

| 日 | やること（各15分） |
|---|---|
| 1日目 | 「もしも」を紙に書き出して、3つに仕分ける |
| 2日目 | 必携品チェックリスト5つを、自分の言葉で埋める |
| 3日目 | 保存した投稿から1つ選び、「劣化版」を作る |
| 4日目 | 1行投稿する |
| 5日目 | 反応を見て、1行メモ（0でもOK） |
| 6日目 | 「もし〇〇したら、△△」を1つ決める |
| 7日目 | 1週間で「出した数」を数える |
| 8日目 | ミュートしたい投稿を、1つミュートする |
| 9日目 | 投稿を1つ、直して出し直す |
| 10日目 | 「先月の自分」と比べて、1つ進んだことを書く |
| 11日目 | 1行投稿する |

## 安全のための注意（ここは大事です）

この記事の「最低限の装備で歩き出す」は、**発信・副業の話**です。

**実際の登山では、必携品や登山計画を省かないでください。**
- 天気や気温の確認、登山計画書の提出、地図、水、ライト、救急セット、雨具などを、省かないこと
- リュックの重さは、日帰りで体重の約10%が一つの目安とされています（海外の登山情報が中心で、日本の公的な基準は確認できていません。体力やコースで変わります）
- 無理だと感じたら、**引き返す**

「荷物を減らす」の意味は、**「命を守る荷物は持つ。不安だけの荷物は下ろす」**です。
