# ai7-tools
@ai_7days_labの自作ツール置き場。Claude/Claude Codeで作ったツールをまとめて公開しています。

## カテゴリ

| カテゴリ | 内容 | フォルダー |
| --- | --- | --- |
| ブックマーク整理 | ブックマーク判定チェッカー | `bookmark-checker/` |
| 学術論文 | エビデンス・ラボ | `evidence-lab/` |
| **試作・実験** | くらしの試作ラボ。ごみ分別・子育てコンパスなど | [`prototypes/`](prototypes/) |

藤森式のキッズ向け教材・アプリは、別のリポジトリで管理する方針です。

試作は公式製品ではありません。各アプリの収録範囲・出典・データ時点を確認して利用してください。
